# Resume-Ranker

## About the Project
Resume-Ranker is a full-stack web application that uses AI to help users improve their resumes. It analyzes resumes and provides feedback to help users tailor them to specific job descriptions.

## Features
- **User Authentication:** Register and log in securely.
- **Resume Analysis:** Analyze resumes and receive feedback.
- **Resume Customization:** Tailor a resume according to a job description.
- **User Profile:** Access personal information and previous resume activities.

## Technologies Used
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT)
- **AI Integration:** OpenRouter API

## Project Structure
- `client/` – Frontend application
- `server/` – Backend application

## Learning Objectives
This project helps demonstrate concepts in full-stack web development, API integration, database operations, user authentication, and AI-based resume processing.
